# Music navigation fixtures

Unmodified upstream scripts used to exercise actual custom-element lifecycles and
APlayer audio playback without relying on external CDNs or music services:

- https://cdn.jsdelivr.net/npm/aplayer@1.10.1/dist/APlayer.min.js
- https://cdn.jsdelivr.net/npm/meting@2.0.2/dist/Meting.min.js

Their MIT licenses are included alongside the scripts. Tests provide a local
playlist using the existing `/media/shortcodes/flower.mp4` sample.
