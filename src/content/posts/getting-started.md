# 开始使用 Astro Solitude

欢迎使用 **Astro Solitude**。本篇是通用演示内容，可以直接替换为自己的文章。

## 内容与表达

主题把内容、配置和页面组件分开。文章保留在 `src/content/posts`，站点配置位于 `src/site.config.ts`。

> 让内容自然成为主角。

## 开始创作

- 使用 Markdown 编写文字。
- 使用 MDX 组合提示、图库与媒体。
- 在明暗主题下阅读相同内容。

```typescript
const message: string = "Hello, Solitude";
console.log(message);
```
